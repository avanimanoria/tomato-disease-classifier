## Failures found by the gate (and how they were fixed)

1. **Phase 4: `LegacyMissionGoldenTest/testPhase0Snapshot`, `MATLAB:nonExistentField`.**
   - Cause: the Phase-0 golden cfg was saved before `localization.geolocateTargets` existed, and the engine read the field unguarded. A real backward-compatibility bug for any saved config.
   - Fix: an `isfield` guard in `runInternal2Scenario.m`. All later new-field reads were written with the same guard.
2. **Phase 5: `CoverageDecompositionTest/testInfeasibleFailsClosed`.**
   - Cause: the infeasibility error message passed vectors to `error()`, which raised `MATLAB:error:nonScalarInput` instead of `planCoverageDecomposition:infeasible`. It still failed closed, but with the wrong identifier.
   - Fix: scalar arguments.
